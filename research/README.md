# Richping Research Inbox

This directory stores durable, normalized research hypotheses. It is not a production strategy directory and it does not contain performance evidence by itself.

- Contract: [docs/RESEARCH_CAPTURE.md](../docs/RESEARCH_CAPTURE.md)
- Template: [templates/hypothesis.yaml](templates/hypothesis.yaml)
- Canonical hypotheses: `hypotheses/HNNNN-rNN.yaml`

A chat discussion, screenshot, intuition, or GitHub issue is an input. A hypothesis file records exactly what should later be tested. Existing Richping experiment/evaluation contracts remain the authority for evidence.

Do not delete rejected hypotheses. Do not promote a hypothesis by editing its status without linked versioned evidence.
